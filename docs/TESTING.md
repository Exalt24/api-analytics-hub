# Mutation history and review passes

The long form of what the README's Testing section summarises. Each figure names its output file; the guards were run in a copy of the repository because the harness edits source in place.

**Run dates.** Python: run of 2026-11-07 ([output](test-runs/2026-11-07-full-pytest.txt); the skips are the stripe-mock and pg_dump tests, which run in CI); web: 2026-11-10. The ad and business connectors have their own run ([output](test-runs/2026-11-07-ads-business-pytest.txt)). 22 deliberate breakages of them each turned a test red ([output](test-runs/2026-11-07-ads-business-mutation.txt)).

Of the 300 hand matched guards, 91 are new; the 97 aimed at the report, the services and the migrations went red on 2026-10-26, the 25 for price watch ([output](test-runs/2026-10-30-price-watch-mutation.txt)) and the 35 for billing ([output](test-runs/2026-10-30-billing-mutation.txt)) on 2026-10-30, the 11 for the Stripe SDK on 2026-10-31, and the other 132 were not rerun. The 2026-10-26 code was also mutated from its syntax tree (`tests/derived_guards.py`, driven by the author's `mutate_ast.py`, not in this repository): 2,779 mutants in 14 files, 2,662 killed, 117 survived, 90 of them a `|` in a type annotation and 27 read and equivalent ([table](test-runs/2026-10-26-derived-guards.txt)). Blind review of the ads, search and monthly run code ran 159 cases in four passes: seven findings were fixed by class, six are known limits pinned by tests, and 191 of 201 mutants of the fixes were killed, the rest read ([cases](../tests/corpus), [round 2](test-runs/2026-10-26-output-round-2-mutation.txt), [limits](MONTHLY_REPORT.md#limits)). No pass after the second round was run.

**2026-11-07, the ad platform and business system connectors.** 22 deliberate breakages of the new code (a payment counted on its UTC day, a retry loop that never hands a long wait back, a cost per conversion that divides all spend, a money check that forgets a new key, and others), each run in a copy, each turned a test red ([output](test-runs/2026-11-07-ads-business-mutation.txt)). `tests/test_vendor_common.py` and `tests/test_adspend_view.py` also run their rules over 300 seeded worlds each with mutation controls. No blind review pass has been run on this code.
